# Log Analytics

This folder contains Log Analytics-related content for Microsoft Sentinel and Azure Log Analytics environments.

## Contents

### Queries
The `queries/` folder contains KQL (Kusto Query Language) queries designed to help with threat detection, incident investigation, and security monitoring in Log Analytics workspaces.

## Contributing

When adding new content to this folder, please ensure:
- KQL queries are stored in the `queries/` folder with a `.kql` file extension
- Each query includes a brief description of its purpose
- Include any required table names and data sources needed
- Follow KQL best practices for performance and readability
